    Method details load with the data file.

    Each figure is the median of the midpoint of the range each posting published. Where a posting publishes a single figure, that figure is its own midpoint. Nothing is estimated, inferred, or filled in. These are advertised ranges, not paid compensation, and the interval shown describes sampling noise inside this snapshot only. It says nothing about how well this board represents the wider market.

    The statistics are produced by the same script that produces our Salary Transparency Report, imported as a module rather than copied, so the two cannot drift apart. The bootstrap uses a fixed seed, so the same snapshot always yields the same interval.

    Related: the Salary Benchmarker compares this board against outside survey and employer data. The roles board is the underlying source, one row per posting, with a link to each original listing.

    Before you cite or negotiate. This is a premium opportunity market, not a national median. Every posting here clears a published midpoint of $100,000, so the low end of the real market is missing by construction. Postings concentrate in the Bay Area and New York. A median built on a small slice can move a long way when one posting is added or expires, which is what the sample size and the interval beside each figure are for.
